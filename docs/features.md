# 기능 명세 (개발 계획서 v1.1 기준)

Must 20 · Should 6 · Could 4. 담당: A iOS · B 웹 뷰어 · C 소셜·실시간 · D 엔진 · E 백엔드·통합.

입력 방식은 **정밀 모드**(LiDAR 아이폰 Pro)와 **자유 모드**(모든 기기, 웹) 두 가지다.

## ① 방 생성

| ID | 기능 | 우선순위 | 담당 | 완료 기준 |
| --- | --- | --- | --- | --- |
| M1-1 | 정밀 모드: RoomPlan 스캔 → `RoomData` 변환·업로드 | Must | A | 실측 대비 벽 길이 오차 ±3cm (팀원 방 3곳) |
| M1-2 | 자유 모드: 치수 입력 (직사각형 + 문·창문 최대 4개, 창문 방향) | Must | B | 입력 후 3초 내 3D 생성 |
| M1-3 | 자유 모드: 원룸 템플릿 3종 (4·5·6평) | Must | A(데이터) + B(UI) | 선택 후 치수 수정 가능 |
| M1-4 | 자유 모드: ㄱ자·다각형 꼭짓점 편집 | Should | B | 꼭짓점 8개, 직사각형 완료 후 착수 |
| M1-5 | 자유 모드: 평면도 이미지 배경 따라 그리기 | Could | B | 기준선 1개로 스케일 보정 |
| M1-6 | 평면도 자동 벽 인식 | Could | D | 단순 원룸 인식률 70% |
